INSTALLATION SUR GITHUB
1. Ouvrir le dépôt send-labs-site.
2. Add file > Upload files.
3. Envoyer TOUT le contenu de ce dossier à la racine.
4. Remplacer les anciens fichiers si nécessaire.
5. Commit changes.
6. Attendre le redéploiement Vercel.

AJOUTER UNE PHOTO
- Déposer le fichier dans assets/images.
- Utiliser un nom simple, sans espace, par exemple garde-boue-1.jpg.

AJOUTER UN PRODUIT
- Ouvrir data/products.json.
- Copier un objet produit existant.
- Modifier id, name, price, category, image, short, features et stock.
- Respecter les virgules et guillemets JSON.
