GESTION SIMPLE

Ajouter des produits sans dashboard.

Cette page explique la méthode actuelle. Elle n’est pas une interface administrateur sécurisée.

1. Photos

Ajoute les images dans assets/images.

2. Produits

Modifie data/products.json avec le nom, le prix, l’image et le stock.

3. Publication

Envoie les modifications sur GitHub. Vercel redéploie automatiquement.

Pourquoi pas de compte admin maintenant ?

Un vrai compte administrateur nécessite une authentification et une base de données. Une fausse page admin en HTML exposerait le mot de passe et ne serait pas sûre. Avec seulement quelques produits, modifier le fichier JSON est plus simple et plus sécurisé.
